# Module `:feature:group`

Chứa giao diện & logic xử lý cho cụm **Chia tiền nhóm & Tất toán nợ**:

- **Feature 19:** Roommate / Travel Group Management (Room N-N)
- **Feature 20:** 4-Mode Group Expense Splitting (Đều, %, Cố định, Theo món)
- **Feature 21:** Debt Path Optimization (Thuật toán Min-Cash Flow $\le N - 1$)
- **Feature 22:** One-Tap Debt Payment (VietQR cá nhân & xác nhận đã trả)
- **Feature 23:** Group Settlement Export (PDF / `.xlsx` / CSV)
- **Feature 24:** Group Cash Flow Timeline & Safe Revert

Gợi ý chia file bên trong package: `GroupContract.kt`, `GroupViewModel.kt`, `GroupScreen.kt`.
