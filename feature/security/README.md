# Module `:feature:security`

Chứa giao diện & logic xử lý cho cụm **Bảo mật, Sao lưu & Cài đặt**:

- **Feature 28:** Biometric & 6-Digit PIN App Lock (PBKDF2, Auto-lock 30s)
- **Feature 29:** AES-256 Encrypted Backup & Restore (`.wallet` + SHA-256)
- **Feature 30:** Currency (`VND/USD/EUR`), Dark/Light Theme & Personal Report Export (PDF / `.xlsx` / CSV)

Gợi ý chia file bên trong package: `SecurityContract.kt`, `SecurityViewModel.kt`, `SecurityScreen.kt`.
